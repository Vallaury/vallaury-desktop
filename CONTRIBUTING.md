# Contributing

The app is small on purpose. Features belong on the website, not here. A change that adds a permission, a dependency or a network call will be declined unless it is clearly needed. Open an issue first for anything bigger than a small fix.

By sending a patch you agree that it is released under [GPL-3.0-only](LICENSE).

```sh
npm install && npm test
```

Plain, short commit messages in the imperative. Do not commit certificates, keys or build output.
