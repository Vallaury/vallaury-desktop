# Security

Please do not open a public issue for a vulnerability. Use GitHub's private reporting (**Security > Report a vulnerability**) or write to <privacy@vallaury.it> and say it is about the desktop app. Include the version, the system, and how to reproduce it.

In scope: leaving the allowed address, the `vallaury://` link handling, the bridge the page can call, and the update path. Only the latest release is supported.
